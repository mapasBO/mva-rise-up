# Tarija - Map gallery

All maps are A4 layouts exported from `MVA_Tarija.qgz` (script `scripts/tarija/phase3b_layouts.py`), 24 maps, shown here at 150 dpi. Click a map to open it full size. Legends are bilingual (EN/ES). Values 0-1, 1 = highest vulnerability.

**Reading the maps.** Indicator and dimension rasters use 5 fixed classes 0.2 wide; BIO2, BIO3 and URB3 are categorical. Hexagon maps use the guide classes (0-0.33-0.66-max). The combined maps also use complementary classes (standard deviations or quintiles) because with fixed classes almost all of Tarija falls in one class; these show *relative* hotspots within Tarija, not absolute high vulnerability (see [04](04_phase3_hotspots.md)). The 14 labelled neighbourhoods are spread evenly; the neighbourhood layer covers only the consolidated centre (34% of the urban area).
