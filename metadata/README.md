# Metadata / Metadatos

`tarija/`: QGIS metadata files (.qmd, English and Spanish in the same file) for the 11 indicators, the 3 dimension vulnerabilities and the combined vulnerability. Load them in QGIS with *Layer Properties > Metadata > Load Metadata*. History entries record each processing step.

`tarija/`: archivos de metadatos QGIS (.qmd, inglés y español en el mismo archivo) de los 11 indicadores, las 3 vulnerabilidades por dimensión y la vulnerabilidad combinada. Se cargan en QGIS con *Propiedades de la capa > Metadatos > Cargar metadatos*. El historial registra cada paso de procesamiento.
